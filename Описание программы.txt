Программа поиска корня уравнения методом бисекции
Описание программы

Данная программа представляет собой консольное приложение на языке Java, предназначенное для нахождения приближенного значения корня нелинейного уравнения численным способом.

Программа решает конкретное математическое уравнение: x^3 - x - 2 = 0

Программа работает через командную строку (терминал). При запуске оно не выполняет расчеты мгновенно, а сначала запрашивает у пользователя исходные данные. Это делает программу гибкой: ее можно использовать не только с настройками из домашнего задания, но и для любых других отрезков или точности без изменения самого алгоритма.

Основные возможности:

Интерактивный ввод: Пользователь может ввести свои значения границ a, b и точности ε. Если пользователь просто нажимает клавишу Enter, не вводя число, программа автоматически подставляет стандартные значения (a=1, b=2, ε=0.0001).
Проверка условий: Перед началом расчетов программа проверяет, применим ли метод к выбранному отрезку. Она вычисляет значения функции на краях и убеждается, что один результат положительный, а другой отрицательный.
Визуализация процесса: В ходе работы выводятся промежуточные значения функции на границах, чтобы пользователь мог видеть логику сужения интервала.
Подробный отчет: По завершении работы программа выводит найденный корень, количество выполненных шагов и проверку результата (значение функции в найденной точке), которое должно быть близко к нулю.
Описание алгоритма (Метод деления отрезка пополам)

Алгоритм основан на теореме о промежуточном значении. Если непрерывная функция на концах отрезка имеет разные знаки, то между ними обязательно есть точка, где график пересекает горизонтальную ось (то есть f(x) = 0).
